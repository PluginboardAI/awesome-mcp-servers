## How entries get here

- **Scanned.** Pluginboard scans every listing on each change, and again when its rules improve. Only listings whose latest scan passed are listed here. Anything with a warning stays on the site but not in this list.
- **Ranked.** Within a category: installs in the last 7 days, then total installs, then GitHub stars. Each category shows its top 15, and the list holds at most 200.
- **Current.** This list is generated from the live catalog, so please don't edit it by hand.

## Add yours

Makers can list MCP servers for free at [pluginboard.ai/submit](https://pluginboard.ai/submit). Once it's live and its scan passes, it can appear here automatically.
